# Тату Старт — міні-курс Вікторії Поникарової (14 €)

Лендинг міні-курсу VIP tattoo school: UA (`index.html`) і RU (`ru/index.html`).
Чистий HTML/CSS/JS, без збірки та залежностей на сайті. Бренд-токени взято з основного лендингу VIP tattoo school.

## Оплата (Stripe)
1. Stripe Dashboard → **Payment Links** → створити лінк на 14 € (EUR).
2. У налаштуваннях лінка: **After payment → Redirect** → `https://t.me/mentor_tatoo_Viktoria_bot` (бот видає доступ).
3. Вставити лінк у `config.js` → `stripeLink`.

Поки `stripeLink` порожній, усі кнопки «Забрати за 14 €» ведуть в особистий Telegram Вікторії.

## Шрифти (як на еталонному лендингу, Google Fonts)
- **Montserrat** 400/700 (+ курсив): заголовки й весь текст.
- **Roboto** 400/700: кнопки.
- **Poppins** 400–700: sticky-панель знизу.
- Розміри (десктоп / планшет / мобільний): hero 40/39/34, заголовок секції 32/31/24, h3 24/23/22, підзаголовок 18, текст 16, підпис 14. Задано змінними `--fs-*` на початку `style.css`.

## Редагування текстів
Усі тексти обох мов — у словниках `UA` / `RU` у `scripts/build.py`.
Після змін: `python3 scripts/build.py` (потрібен лише Python 3). Це перегенерує `index.html` і `ru/index.html`, тому мови завжди залишаються дзеркальними.

## Публікація
Статичний сайт: GitHub Pages (Settings → Pages → гілка + корінь `/`), Netlify, Vercel або вставка у WordPress.
Перед публікацією перевірте `SITE` у `scripts/build.py` (canonical / og:url) і вкажіть реальний домен.

## Що підтвердити перед запуском
- Цифри (300+ випускників, 22+ країни, 12 студій-партнерів) і нагороди взято з матеріалів школи; у їхньому `HANDOFF.md` ці дані позначені як непідтверджені документами.
- Публічна оферта: у футері лише реквізити (NIP). Додайте посилання на оферту, коли вона буде.
- Зворотний зв'язок по завданнях і тривалість уроків (30–60 хв/день) — уточніть у Вікторії.
